# Team 9 project bundle

This private release contains code, notebooks, measured experiment results, and
submission materials for Classification of Legal Text.

- `team9-project.zip`: source project, notebooks, evidence, report, and presentation.
- `team9-model-bundle.zip`: saved models and the training-opinion retrieval index.
  Extract inside the project to create `artifacts/`.
- `team9-offline-kit.zip`: complete project including model artifacts. Dependencies
  still need installation. The saved-model demo then runs without internet.
- `SHA256SUMS.txt`: checksums for the three archives.

Use `README.md` for local and Colab setup. Private release access requires repository
access. The raw corpus and Python virtual environment are excluded from all archives.
Preserve the source attribution in the README and provenance files.
